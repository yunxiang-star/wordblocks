### 核心设计：记忆曲线（SRS）

- 9 档台阶，间隔 `STAGE_GAP = [10min, 1d, 2d, 4d, 7d, 15d, 30d, 60d, 120d]`，`MASTER_STAGE = 4`（第 5 档 = 已掌握）。
- `reviewWord(w, grade)`：good → 台阶 +1；hard → 台阶不动、间隔砍半；again → 台阶归零、lapses+1。`known` 字段改成派生值 `stage >= MASTER_STAGE`（不再手写，但仍兼容旧 UI 的筛选）。
- `planSession(deck, {size, mode})`：智能模式留 50% 名额给新词，复习词不够时空位补新词；`mode` 另有 `review` / `new`。复习词按 `urgency()`（逾期天数 + 忘记次数 - 台阶）排序。
- 会话两阶段：learn（回想 + 三档自评）→ quiz（中→英四选一，答错回队尾，同词最多 3 次防死循环）→ done。
- `touchStreak()` 按 `stats.lastDay` 记连续打卡。

### 数据迁移（本次最关键）

- `normalizeWord(w)` 抽成独立函数，`normalize()` 和 `mergeBackup()` 共用（导入旧备份也安全）。
- 判定：`w.stage` 未定义 = 1.x 老数据 → `stage = known ? 4 : 0`；`learnedAt = (known || reviews>0) ? createdAt||now : 0`；`dueAt = 0`（立刻到期）。→ 升级后老词自动进复习队列，不丢也不漏。
- boot 里检测 `loaded.version < 2` → `saveNow()` 并把迁移词数传给升级提示弹窗。
- **升级可行性已核对**：包名相同、证书 SHA-256 与 1.0 完全一致（`2d9a5239…`）、versionCode 1→2、数据文件仍是 `getFilesDir()/wordblocks.json`。
