## 词块 WordBlocks — Android 背单词 App（APK）

用户需求：做一个可装到手机的背单词程序，分多个区块（雅思生词本 / 用英语学线代与微积分），可自行添加单词并自动填中文释义+例句，支持快捷导出 PDF 打印背诵。

### 技术方案（重要，后续迭代沿用）

- **不用 Gradle**。本机无 Java/Android SDK/Homebrew，全部自建：JDK 17 (Temurin) + Android cmdline-tools
  - build-tools 34.0.0 + platforms;android-34，装在 `/Users/illenium/.workbuddy/android/`。
- 构建走 **aapt2 compile/link → javac --release 8 → d8 → zipalign → apksigner**，一键脚本 `WordBlocks/build.sh`。签名密钥 `WordBlocks/keystore/wordblocks.jks`（口令 `wordblocks`）。
- **App 架构**：原生壳（WebView）+ 前端 HTML/CSS/JS 放在 `assets/`。原生只负责 4 件事：JSON 文件持久化、词典网络请求（避开 CORS）、PrintManager 导出 PDF、SAF 备份导入导出。JS 桥名 `Android`，见 `MainActivity.Bridge`。
- **导出 PDF 走系统打印服务**（`PrintManager` + `webView.createPrintDocumentAdapter()`），用户在系统界面选「保存为 PDF」。离屏 WebView 加在 `root` 索引 0（主 WebView 之下）避免遮挡与拦截触摸；300dpi / ISO_A4 / NO_MARGINS，页边距由 CSS `@page` 控制。
- **词典**：本地优先 → `assets/glossary.js`（231 条线代/微积分/微分方程英文术语，离线、释义比通用词典准）；在线兜底 → 有道 `https://dict.youdao.com/jsonapi?q=`（取 `ec.word[0].trs[].tr[].l.i[]` 释义、`ukphone/usphone` 音标、`blng_sents_part.sentence-pair[]` 双语例句），再兜底 MyMemory 翻译。解析逻辑在 `Dict.java`，已用真实接口验证 13/13 命中。
- UI 主题：浅色，主色 `#4C6FFF`；安全区/返回键已处理；`window.wbBack()` 供返回键消费。

### 第二轮（同日下午）：视觉验证 + 修 bug

- **修了一个真 bug**：首页「今日新增」恒为 0。统计读的是 `w.createdAt`，但写单词时只存了`addedAt`（格式化字符串），`createdAt` 从未写入。已在 3 处写入点补 `createdAt: Date.now()`（单个添加 / 批量导入 / 内置词库导入），并在 `normalize()` 补 `createdAt: w.createdAt || 0`。
- `tools/test_ui.js` 增加「5b. 首页今日新增统计」3 项断言，现为 **68 项全通过**，APK 已重新构建（构建后核对过 APK 内 `assets/app.js` 的 SHA-256 与源码一致）。
- **新增无头截图链路**（首次跑通，后续可复用）：
  - `tools/make_shots.py` → 生成 `/tmp/wbshot/{home,deck,study,studyback,add}.html` + `bridge.js`。原理：在 `index.html` 的 `</body>` 前注入 `window.__stage` + DOMContentLoaded 里模拟点击，不改动 `assets/` 源文件。
  - `bridge.js` 作为 `--init-script` 注入，**伪造原生 `window.Android`**（`loadData/saveData/lookup`），这样无头浏览器里也能演示「输入英文自动补全释义+例句」。
  - 用 `agent-browser`（npm 装到`/Users/illenium/.workbuddy/binaries/node/workspace/node_modules/.bin/agent-browser`，Chromium 在 `~/.agent-browser/browsers/`）：`--init-script ... open URL` → `set viewport 390 844`→ `wait` → `screenshot`。**必须用 `run_in_background` 起的静态服务器**，普通 `&` 起的进程在 Bash 调用结束会被回收（表现为 curl 502 / 浏览器 ERR_CONNECTION_REFUSED）。
  - `tools/make_preview_sheet.py` → 拼图成 `preview/词块-界面预览.png`。
- **环境坑（重要）**：
  - 本机 **Firefox 无法做无头截图**：`--headless --screenshot` 一律报 `Could not find profile folder`，自建 profile / 自定义 HOME / 关闭沙箱都无效。截图改用 agent-browser（Chrome for Testing 155）。
